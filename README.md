# 北島病院 システム現状調査ポータル (共同編集版)

本リポジトリは、北島病院のシステム再設計に向けた現状調査の「案内板」です。
GitHub Pagesを利用して、各部署の担当者が迷わずに入力できるように構成しています。

## 🚀 運用フロー

1. **ポータルの公開**:
   GitHub Pagesを有効にし、発行されたURLを事務長および各部署へ案内します。

2. **共有テーブルの作成 (事務長/管理者作業)**:
   - リポジトリ内の `master_table_template.csv` をGoogleスプレッドシートにインポートします。
   - スプレッドシートの「共有」設定を「リンクを知っている全員が編集者」に設定します。
   - 発行されたスプレッドシートのURLを `index.html` の `YOUR_GOOGLE_SHEET_URL_HERE` 部分に書き換えてプッシュしてください。

3. **各部署による入力**:
   - 担当者はポータルサイトにアクセスし、自分の担当項目を確認します。
   - 「共有マスターテーブルを開く」ボタンからスプレッドシートに飛び、直接情報を入力します。

## ⚠️ セキュリティ上の注意

- **個人情報の入力禁止**: 共有テーブルには、患者名・IDなどの個人情報、およびパスワード等を絶対に入力しないでください。
- **アクセス制限**: スプレッドシートのURLが外部に漏れないよう、病院内でのみ共有してください。

## ファイル構成
- `index.html`: 責任分担表と共有テーブルへのリンクを掲示するポータル画面。
- `master_table_template.csv`: Googleスプレッドシート等にインポートして使用する表のテンプレート。
