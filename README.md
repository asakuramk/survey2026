# 北島病院 システム現状調査フォーム (GitHub Pages版)

本リポジトリは、北島病院のシステム再設計に向けた現状調査用Webフォームです。
GitHub Pagesにてホスティングし、各部署の担当者がブラウザから入力して回答データを抽出することを目的としています。

## ⚠️ 重要なセキュリティ警告

### 1. 認証について
本フォームの入口に設定されているパスワード認証（`kitajima2026`）は、**クライアントサイド（JavaScript）のみで動作する簡易的なものです。**
開発者ツールなどを使用すれば容易に回避可能であり、機密情報の保護を目的としたものではありません。あくまで「誤操作防止」および「簡易的なアクセス制限」として機能します。

### 2. 入力禁止事項
本フォームを通じて、以下の情報は**絶対に入力しないでください。**
- **患者の氏名、ID、病歴などの個人情報**
- **サーバーやシステムの管理パスワード、秘密鍵**
- **個人を特定できる機密性の高い連絡先**

### 3. データ保存方式について
本サイトは静的HTML/JSで構成されており、**サーバーサイドのデータベースを持っていません。**
- 入力したデータは、回答者が「保存」ボタンを押した瞬間に、**ユーザーのPC/デバイス上にJSONファイルとしてダウンロードされます。**
- サーバーにデータが送信・保存されることはありません。
- 保存されたJSONファイルは、病院内の安全な経路（内部メール、社内チャット等）で事務長へ送付してください。

## 導入方法
1. リポジトリをGitHubに作成し、本ファイルをプッシュします。
2. `Settings` > `Pages` より、`main` ブランチをソースとしてGitHub Pagesを有効にします。
3. 発行されたURLを事務長および各部署へ案内してください。
